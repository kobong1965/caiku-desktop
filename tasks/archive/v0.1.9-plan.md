# v0.1.9 无边框上传与任务板实施计划

## Dependency order

1. 固化任务记录、今日聚合和款号素材盘发现合同。
2. 在主进程接入任务生命周期、款号列表和安全窗口控制 IPC。
3. 将素材上传改为“选文件 → 选择款号 → 开始分析”向导。
4. 增加自定义标题栏和今日任务板界面。
5. 自动测试、桌面验收、打包并原位更新到 0.1.9。

## Risks and mitigation

- 任务记录与历史 manifest 重复：以 manifestPath 去重，任务记录优先。
- 处理中退出导致任务永远卡住：下次启动把遗留 processing 标为 interrupted。
- 款号包含 Windows 非法字符：沿用 sanitizeFileSegment 并在弹窗显示最终目录名。
- 无边框后无法操作窗口：标题栏限定 drag 区，所有按钮和表单显式设为 no-drag。
- 旧用户状态缺少任务字段：JSON Store 顶层默认合并，任务板可从素材盘 manifest 恢复。

## Verification checkpoints

- A：同日/跨日任务统计与 manifest 去重测试通过。
- B：款号必须在点击分析后选择，后台路径仍受素材盘根目录约束。
- C：窗口控制只通过可信本地页面 IPC 暴露。
- D：任务板存在空、处理中、完成、失败状态及响应式布局。
- E：0.1.9 保留原安装、快捷方式、素材盘和工程状态。
