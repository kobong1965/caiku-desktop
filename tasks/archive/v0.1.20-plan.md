# 服装视频分析标准 v0.1.20 实施计划

## 目标

将 8 条老钱风西裤样片已验收的检测、去字幕、低复用分流、服装语义分类与 4fps 终检方法接入软件批处理，并用同一批样片做回归对照。

## 实施顺序

1. 新增可测试的字幕风险与服装分类策略模块。
2. 新增 OpenCV + GPU LaMa 本机修复桥接；依赖不可用时安全降级。
3. 修改批处理：临时输出、风险分流、修复后 OCR、最终目录落盘和 manifest 统计。
4. 更新进度文案、设置说明与打包资源。
5. 运行单测、静态检查和 8 条样片黄金回归。
6. 构建补丁版本并验证用户状态、安装位置和快捷方式连续性。

## 风险与处理

- 大面积文字覆盖人物或裤装：不强修，转入 `98_低复用待复核`。
- 本机缺 Python、CUDA、OpenCV 或 LaMa：不伪造成功，含字幕片段转入低复用。
- 视觉模型漏报或误报：普通检测与模型判断交叉验证，修复后重新 OCR；疑似结果必须复核。
- 更新影响现有数据：构建和安装前后校验状态文件与快捷方式，不以默认数据覆盖用户状态。

## 验证检查点

- `npm run check`
- `npm test`
- 8 条样片黄金回归：8 / 37 / 17 / 最短 2 秒 / 0 确认字幕残留
- 构建及本机连续性检查
