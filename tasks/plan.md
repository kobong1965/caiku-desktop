# 裁库 0.1.11 自动更新与 GitHub 发布计划

- 规格：`docs/裁库GitHub自动更新与发布_v0.1.11规格.md`
- 目标版本：`0.1.11`
- 发布仓库：`kobong1965/caiku-desktop`
- 状态：已完成并于 2026-08-21 发布 `v0.1.11`

## Dependency Graph

```text
P0 发布与数据基线
  ↓
P1 更新服务合同测试
  ↓
P2 主进程、preload 与设置页
  ↓
P3 全量回归与 Windows 构建
  ↓
P4 GitHub 源码与 Release 发布
  ↓
P5 原位安装、数据连续性与下载验收
```

## Phases

### P0：发布与数据基线

- 确认 GitHub 登录账号与目标仓库可用性。
- 记录当前安装位置、桌面快捷方式、用户状态文件哈希和业务数据计数。
- 明确公开仓库排除项与 Release 资产清单。

### P1：更新服务合同测试

- 为更新事件到 UI 状态的映射、重复操作保护和错误序列化建立单元测试。
- 为 preload IPC、设置页结构、按钮状态和更新元数据建立合同测试。

### P2：实现更新功能

- 接入 `electron-updater`，注册检查、下载、安装 IPC。
- 在 preload 暴露窄接口和状态订阅。
- 增加“设置 > 软件更新”页面、下载进度和状态反馈。
- 配置 GitHub provider、版本号和生成元数据。

### P3：回归与打包

- 运行语法检查与全部测试。
- 构建 0.1.11 安装版、便携版、blockmap、`latest.yml`。
- 计算 Release 资产 SHA256。

### P4：GitHub 发布

- 初始化 Git 仓库，仅提交允许公开的工程文件。
- 创建公开仓库并推送默认分支。
- 创建 `v0.1.11` 正式 Release，上传全部发布资产。

### P5：安装与线上验收

- 原位安装 0.1.11，从原快捷方式启动。
- 对比安装前后用户状态文件哈希、安装路径和快捷方式目标。
- 验证 GitHub Release 页面与安装版直链可访问。

## Completion Gate
