# 剪辑智能体训练系统 v0.1 实施计划

## 目标

在不破坏 v0.1.23 素材分类与字幕清理验收基线的前提下，升级现有剪辑智能体，使其只分析用户主动投喂的市场脚本视频，读取素材分类板块已经人工确认的款号分类清单，按脚本逐句从对应分类选材，并输出配音、字幕和叙事逻辑一致的成片。智能体不二次筛选素材，也不接入千川数据或评分。

## 依赖关系

```text
训练案例库
    ↓
用户投喂视频 → 市场脚本模式提取 → 脚本模式库
    ↓                         ↓
人工确认的素材分类清单 ─→ 用户案例检索
    ↓                         ↓
逐句画面绑定 + 叙事状态机
    ↓
时间线优化 → 配音/字幕对齐 → 逻辑与质量门禁
    ↓
用户接受/修改/拒绝反馈 → 新版案例
```

## 实施阶段

### 阶段 1：训练合同、案例库与市场脚本分析

1. 定义训练案例、脚本模式、人工确认素材分类清单、逐句画面绑定和反馈版本的数据合同。
2. 新增本地训练仓库，保存到素材盘 `_裁库智能体/训练库`；只保存索引和派生结果，不复制原视频。
3. 升级参考视频分析，把用户主动投喂的视频拆成问题钩子、叙事顺序、镜头角色、切点、口播、字幕和音乐结构；不实现市场搜索、抓取、下载或自动发现。云端分析仅调用用户已配置的模型端点。

### 阶段 2：分类清单读取与用户案例检索

4. 直接读取素材分类板块保存且经人工确认的款号分类 manifest，完整保留每个分类及其素材项，不运行字幕、质量、款号或其他二次筛选。
5. 只从用户投喂的训练案例库中，根据商品类目、脚本意图、镜头角色和风格检索 3–5 个高质量相似案例；不从互联网获取案例。

### 阶段 3：逐句选镜与叙事连续性

6. 为每句脚本建立 `sentenceIntent`，明确它要表达的卖点、需要的镜头角色、必要商品证据和允许的转场关系。
7. 用叙事状态机约束“问题钩子 → 细节证据 → 上身结果 → 使用场景 → 轻 CTA”，阻止跳题、重复结论、无证据文案和顺序倒置。
8. 智能体只能从当前人工确认的素材分类清单中选镜，并为每个选择记录素材分类、片段和引用案例；不得删除、降级或改类。

### 阶段 4：配音、字幕、质量门禁与学习反馈

9. 复用现有千问语音链路；配音、屏幕字幕和时间线共用同一份逐句文本，支持无口播纯音乐模式。
10. 渲染前运行硬门禁：逐句画文对应、叙事连续、音画时长对齐、重复镜头、字幕清理、2 秒、完整构图和静音状态。
11. 用户接受、拒绝、换镜、改切点、改文案时保存新版本和原因，不覆盖历史；不读取千川指标。

### 阶段 5：简化 UI、黄金测试与本机更新

12. 在“脚本管理”增加“市场脚本学习”拖入区，在“素材混剪 / AI 编排”显示已读取的分类清单、逐句选镜理由和逻辑门禁结果；所有用户可添加项保留删除入口。
13. 新增固定西裤脚本黄金样例，并回归 v0.1.23 已验收素材分类与字幕清理基线。
14. 通过全量测试后只升级补丁版本，原安装位置、桌面快捷方式、用户设置、历史素材引用和项目数据保持不变。

## 风险与处理

- 参考视频里的商品事实污染当前款号：只学习用户投喂视频的结构和镜头决策，不把参考商品信息写进当前脚本。
- 分类素材过多导致模型上下文失控：完整保存人工确认的分类清单，用分页和分类索引提供上下文；不得以缩减上下文为由删除或二次筛选素材。
- 低质量案例带偏智能体：低分、拒绝、错款、删除和未授权案例只能作反例，不能进入正向检索。
- 为补时长加入无关镜头：宁可阻止渲染并提示缺少素材，也不允许跳题填充。
- 智能体越权重复判断素材：分类 manifest 是唯一真相源；字幕、拆分、静音、分类和人工筛选仍只在素材分类板块完成。

## 验证检查点

1. 数据合同与训练仓库单元测试。
2. 用户投喂视频的市场脚本模式提取黄金测试、本地模型断网测试和外部视频发现禁用测试。
3. 人工确认分类清单完整读取和用户案例检索测试。
4. 逐句画面绑定与叙事连续性测试。
5. 配音、字幕和时间线对齐测试。
6. 固定西裤脚本端到端计划测试。
7. `npm.cmd run check` 与 `npm.cmd test` 全绿。
8. v0.1.23 字幕清理黄金回归、本机安装和快捷方式连续性检查。
