# UI 设计规格 v1 草案（旧视觉基线，已停止使用）

> 2026-08-17 更新：本文早期的仪表盘式首屏不再作为最终 UI。最终版改为以“导入原片 → 切分分类 → 清除字幕 → 自动混剪 → 导出成片”为主线的素材生产工作台，详见 `prototype/v1/` 与 `docs/V1最终交互说明.md`。

> 设计方向：沿用参考图的“高密度模块化桌面工作台”效果，改为白色背景、黑色文字、浅灰层级和少量薄荷青状态色。

## 1. 第一轮设计范围

第一轮只设计一个完整的桌面首屏“素材工作台”，同时建立可复用的基础样式和组件。待该方向确认后，再扩展素材入库、分类校对、去字幕和混剪页面。

首屏要让用户在 5 秒内看清：

- 当前选择的款号和素材批次。
- 视频总数、可用片段数、总素材时长和存储占用。
- 当前处理到了哪一步、是否有失败任务。
- 自动分类的分布。
- “片段不得短于 2 秒”规则是否生效以及本批处理结果。
- 下一步可以导入素材、检查分类或开始混剪。

## 2. 视觉语言

### 2.1 色彩令牌

| 令牌 | 色值 | 用途 |
|---|---|---|
| `canvas` | `#F5F5F2` | 应用背景 |
| `surface` | `#FFFFFF` | 卡片、侧栏、弹层 |
| `ink` | `#111111` | 主文字、主按钮 |
| `muted` | `#6B6B68` | 次级文字 |
| `line` | `#E5E5E0` | 分割线、卡片边框 |
| `soft` | `#EEEEEA` | 次级块面、空状态 |
| `accent` | `#C8F4E8` | 选中、成功、重点状态 |
| `accent-strong` | `#2E8B72` | 图表和成功文字 |
| `warning` | `#F2B94B` | 需检查状态 |
| `danger` | `#D94C45` | 失败、低于 2 秒 |

整体保持黑白为主。薄荷青只用于选中、完成和关键数据，不做大面积品牌底色。

### 2.2 字体

- 中文：Microsoft YaHei UI。
- 数字与英文：Segoe UI Variable。
- 页面标题：24/32，Semibold。
- 卡片标题：14/20，Semibold。
- 正文：13/20，Regular。
- 大数字：32/36，Semibold，使用等宽数字特性。

正式写入 Figma 前需要检查字体是否可用；缺失时使用可用的等价字体替代。

### 2.3 形状与层级

- 页面外框圆角：18 px。
- 主卡片圆角：16 px；小组件圆角：10–12 px。
- 卡片边框：1 px `line`。
- 阴影只用于浮层和主操作卡片，避免整个界面发灰。
- 8 px 间距体系；常用间距为 8、12、16、24、32。

3. 分类校对
4. 字幕处理
5. 脚本混剪

## 6. 2 秒规则的界面状态

### 正常状态

- 规则卡显示“最短片段 2.0 秒”。
- 完成后显示“已合并 6 个短片段，淘汰 2 个不可用片段”。
- 成功状态使用薄荷青底和黑色文字。

### 处理中

- 显示正在检查的片段数量和进度。
- 进度条仅使用黑色与浅灰，当前步骤可用薄荷青提示。

### 手动裁切不足 2 秒

- 时长标签显示红色，例如 `1.72s`。
- 时间轴选区边缘变红。
- 底部固定提示：“片段不能短于 2 秒，请扩大选区或与相邻片段合并。”
- “保存片段”按钮禁用，“合并相邻片段”作为可用次级操作。

### 无法自动合并

- 状态为“不可用”，并显示原因“时长不足且前后语义不连续”。
- 用户仍可打开原视频重新选取，不自动永久删除。
