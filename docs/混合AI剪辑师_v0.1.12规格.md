# 裁库混合 AI 剪辑师 v0.1.12 规格

## 1. 目标

把现有“云端千问做素材分类、本地 Qwen3.5 做剪辑规划”的两套孤立链路，升级为一名能根据真实素材证据做决策的服装短视频剪辑师：

- 素材分类、对标视频分析、脚本到素材编排共用同一套路由策略。
- 默认使用通义千问 API 保证视觉理解和复杂规划质量；网络或密钥不可用时由本机 Qwen3.5 兜底。
- 脚本要求的卖点没有对应素材证据时，禁止伪造动作或硬配画面，必须标记缺口、选择诚实替代镜头并给出改词建议。
- 每次结果记录实际 provider、model、mode 与是否发生回退，便于追溯成本和质量。

## 2. 已确认产品决策

### 2.1 三种运行方式

| 模式 | 素材分类 | 对标分析/剪辑规划 | 适用场景 |
| --- | --- | --- | --- |
| 智能混合（默认） | qwen3.7-flash，失败转本地 Qwen3.5 | qwen3.7-plus，疑难结构可升级 qwen3.8-max，失败转本地 | 日常生产 |
| 云端高精度 | 云端，不静默使用本地 | 云端，允许疑难升级 | 稳定网络、追求质量 |
| 本地隐私 | 本地 Qwen3.5 | 本地 Qwen3.5 | 断网或素材不出机 |

稳定生产默认使用快照模型：

- 批量视觉分类：`qwen3.7-flash-2026-07-15`
- 对标分析与剪辑规划：`qwen3.7-plus-2026-05-26`
- 疑难复核：`qwen3.8-max`
- 本地兜底：`qwen3.5:latest`，Ollama 环回地址

### 2.2 成本闸门

- qwen3.8-max 不参与普通批次，仅在首轮返回低置信度、结构冲突或不可执行结果时升级。
- 默认每个素材片段抽取 4 帧；本地与云端复用同一批帧，不重复解码。
- 启发式旧规则只作为最后一级应急兜底，结果必须标记“待人工复核”，不能显示为 AI 分类。

## 3. 服装剪辑师能力合同

仓库内新增 `caiku-fashion-editor` Skill，作为运行时提示词的唯一业务规则来源。核心合同：

1. 先读素材能力卡，再读脚本卖点，最后安排时间线。
2. 只能引用本次勾选的素材 ID；时间点不得超出素材时长。
3. 区分直接证据、间接证据、缺失证据。
4. 弹力、下蹲、防水等可验证卖点必须有对应动作画面；没有时必须删除或改写卖点。
5. 对标视频只提供镜头角色、节奏、转场和信息顺序，不得覆盖本批素材的真实证据。
6. 输出必须为可校验 JSON；程序端继续做 ID、时长、证据缺口和安全替代校验。

## 4. 数据与兼容性

- 不迁移、不清空现有素材盘、manifest、脚本、工程、任务板、设置和加密 API Key。
- 旧版 `aiClassification.model` 与 `aiEditor` 配置自动映射到新结构；未配置新字段时使用默认值。
- `caiku-state.json` 只做顶层合并式迁移，原有未知字段原样保留。
- 新生成的 manifest 增加运行策略与实际模型记录；旧 manifest 保持可读。

## 5. UI 要求

- “设置 > 大模型”增加运行方式、批量分类模型、剪辑规划模型、疑难复核模型、本地模型和成本闸门。
- 清楚显示哪些内容会上传云端；本地隐私模式要明确显示“素材不出机”。
- 素材混剪页的剪辑师徽标与进度文案显示实际路由，不再固定写“本机 Qwen3.5”。
- 所有新增控件具备 label、帮助文字、禁用态、错误态和键盘可达性；最小窗口宽度不溢出。

## 6. 验收标准

- 智能混合模式：有 Key 优先云端；云端失败按策略回退本地；结果记录实际 provider/model。
- 云端高精度模式：没有 Key 时在创建任务目录前阻止执行。
- 本地隐私模式：分类与剪辑规划不读取 API Key、不发起外网请求。
- 缺少弹力/拉伸素材时，计划不得把走动或站立伪装为弹力证据。
- Skill 通过结构校验并随安装包进入 `app.asar`。
- `npm run check` 与 `npm test` 全部通过，Windows 安装包可构建。
- 原位安装后版本为 0.1.12，原快捷方式、安装目录和用户数据保持连续。

## 7. 本版边界

- 本版实现路由、Skill、分类、对标分析、剪辑规划和 UI；不在本版建立向量数据库。
- `qwen3-vl-embedding` 留作下一阶段的大素材库语义检索，不阻塞当前按勾选素材工作流。
- 本轮只构建本地安装资产，不发布 GitHub Release。
