# 裁库 v0.1.21

- 修正常规硬字幕被视觉模型误标为贴纸后跳过去字幕的问题。
- 普通字幕覆盖人物或商品主体时仍进入 GPU 修复，并由修复后 OCR 与 4fps 本机终检把关。
- 4fps 字幕框会扩展成连续时间蒙版，清除打字动画首尾的单字和光标残留。
- 本机连续识别到多层截图或拼贴图文时保留原片进入低复用，不再强行补画。
- 真正的截图、商品卡、拼贴、抠图、放大镜和大面积营销图文继续进入低复用待复核。
- 兼容千问把字幕、覆盖层信息返回在 `detected` 子字段的情况，避免识别结果在分流阶段丢失。
- 服装或配饰本体上的品牌 Logo 保留原画，不再误判成后期贴纸。
- 修复后千问若发现 4fps 漏检的片尾字幕，会自动启动第二遍描边文字局部 LaMa 修复并再次终检；宽容模型坐标误差，但不误伤服装与地毯亮纹。
- 新增普通字幕与贴纸标签冲突、主体重叠、实物 Logo 和二次修复区域的自动回归测试。
