# 裁库 v0.1.26

## 本次修复

- 修复“买西裤最怕什么”中的单字“最”被误判为阻断级极限词的问题；“最怕、最近、最后、第一眼”等正常语境不再被误杀。
- 极限词规则改为检查“最好、最佳、最强、销量第一、全网”等明确商业绝对化表达，真正风险词仍会阻止生成。
- “不一定、不保证、并非、无法”等否定说明不再因为包含保证性词根而误报。
- 脚本预检与正式混剪统一检查最终实际播出文本：全程口播检查口播文字，纯音乐脚本检查屏幕字幕，不再出现预检通过、生成时突然失败。
- 混剪前会先完成同一份文案检查；如果真的阻断，会显示所在段落、命中词、原句、原因和修改建议，并提供“去修改脚本”入口。
- IPC 错误现在同时保留 `details` 和旧版 `report`，不再把可处理的问题退化成“错误 / 请检查文件后重试”。
