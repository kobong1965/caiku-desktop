# 裁库 0.1.29

## 重点

- 安装包内置字幕修复 Python 运行时，包含 OpenCV、Torch CPU、TorchVision、NumPy、Pillow、Fire 和 simple-lama-inpainting。
- 安装包内置 LaMa 补画模型 `big-lama.pt`，新电脑安装后不再需要首次联网下载模型。
- 字幕修复运行时优先从安装目录 `resources/caption-runtime` 加载，再回退到用户手动配置路径。
- 字幕修复进程固定传入本地 `LAMA_MODEL`，避免 simple-lama-inpainting 自动联网下载。
- 修复 Torch 在中文路径下直接加载 `.pt` 文件失败的问题，脚本改为通过文件对象加载本地模型。
- 运行时探测会跳过缺依赖的 Python，继续寻找后续可用的内置运行时。

## 验证

- 内置 Python 可导入 `cv2`、`torch` 和 `SimpleLama`。
- `big-lama.pt` 可通过本地文件对象加载。
- 使用内置运行时完成 2 秒带字幕测试视频的字幕补画烟测。
