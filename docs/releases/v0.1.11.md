# 裁库 0.1.11

本版本新增完整的软件更新能力，并首次通过公开 GitHub Release 提供正式下载。

## 新增

- 在“设置 > 软件更新”中主动检查 GitHub 最新正式版本。
- 发现新版本后由用户确认下载，实时显示百分比、文件大小和下载速度。
- 下载完成并通过完整性校验后，可点击“安装并重启”完成原位更新。
- 更新失败可直接重试，不影响素材分类、任务板、脚本管理或混剪工程。

## 发布资产

- `caiku-desktop-setup-0.1.11.exe`：推荐使用的 Windows 64 位安装版。
- `caiku-desktop-portable-0.1.11-x64.exe`：无需安装的 Windows 64 位便携版。
- `caiku-desktop-setup-0.1.11.exe.blockmap`：差异更新元数据。
- `latest.yml`：软件检查更新使用的版本和 SHA-512 元数据。
- `SHA256SUMS-0.1.11.txt`：供人工核对下载文件完整性。

## 连续性承诺

本次更新保持原 `appId`、安装入口、桌面快捷方式和 userData 目录不变，不删除用户素材、脚本、任务记录、本机设置或素材引用。
