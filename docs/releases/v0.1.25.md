# 裁库 v0.1.25

## 本次修复

- 同一条脚本只推断一个共享商品主题，不再因单句出现“衬衫”等搭配词或缺少商品关键词而误报主题跳转。
- 严格时间线完成换镜后重新生成逐句素材绑定、叙事检查与证据检查，不再使用优化前的旧结果阻断最终计划。
- `selectedMaterialIds` 只记录最终实际使用镜头；候选全集单独记录为 `candidateMaterialIds`，便于审计且不会污染逐句检查。
- 人工确认素材已有的直接观察和动作记录可以可靠证明“版型轮廓”和“动态展示”；名称、标签、模型理由和间接观察仍不能冒充直接证据。
- “918 真人短种草”与“918 自然种草口播”的默认克制收口改用“整体展示”，并只迁移仍保持旧默认内容的对应段落，不覆盖用户自定义脚本。
- AI 编排把问题分为“软件需重新校验、脚本需要调整、确实缺少素材、画面证据不足”，逐项给出处理建议，不再把所有阻断都笼统提示为补素材。
