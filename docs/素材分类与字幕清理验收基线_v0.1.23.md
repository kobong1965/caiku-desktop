# 素材分类与字幕清理验收基线 v0.1.23

本文档将已经用户确认通过的“素材分类 + 原视频字幕清理”冻结为后续版本的不可回退基线。剪辑智能体、脚本、配音、音乐和混剪的任何改动都不得破坏本基线。

## 冻结范围

- 原视频只读保留，不覆盖、不改写、不删除。
- 分类片段不低于 2 秒。
- 分类片段默认静音，混剪时只使用指定的配音和音乐。
- 字幕处理禁止通过放大、裁切、拉丝或整块模糊伪装清除。
- 普通硬字幕使用字形蒙版和 LaMa 补画。
- 高难动态字幕使用 `caption-high-fidelity-2026.08.1`：4fps 检测、难度分级、1080 分析宽度、字形级补画和复杂区间分流。
- 字幕复检不通过的素材不得进入可混剪候选池。
- 分类结果可单个播放、全尺寸预览、改分类、标记不可用和删除。

## 金标实片

- 原片：`@做我的啾啾 你家所有上衣都可以搭配的一条老钱风西裤 fit 4K.mp4`
- 难度：100/100 高难。
- 自动识别内部复杂字幕区间：`5.05–7.00 秒`。
- 回归成品：1080×1920、30fps、15.9 秒、H.264、无音轨、完整 9:16 构图。
- 回归报告：`analysis/jiujiu-caption-clean-20260823/software-regression-report.json`。
- 原片 SHA-256 在处理前后必须一致。
