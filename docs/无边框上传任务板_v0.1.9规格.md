# Spec: 无边框窗口、款号归档向导与素材分类任务板 v0.1.9

## Objective

把原素材分类入口改为清晰的批次工作流：用户先选择或拖入一批视频，上传列表读取完成后点击“开始分析”，在弹窗中选择已有款号或新建款号，再由后台将这一批原视频、拆分片段和分类结果写入对应款号素材盘。增加独立任务板，按本机自然日展示今天处理了多少批次、原视频、分类素材、待复核素材及失败任务。桌面窗口取消系统边框，并提供可拖拽的自定义标题栏和最小化、最大化、关闭按钮。

## Assumptions

1. 一次上传批次只归属一个款号。
2. “今天”按运行电脑的本地自然日计算。
3. 已有素材盘一级目录视为已有款号；弹窗允许输入新款号。
4. 分析开始后才建立款号批次目录，原上传位置中的文件不移动。
5. 旧素材、旧批次与旧工程不迁移、不重分类；今日旧批次可从 manifest 补入任务板统计。

## Tech Stack

- Electron 43 / CommonJS 主进程与安全 preload IPC。
- 原生 HTML、CSS、JavaScript 渲染层。
- FFmpeg/FFprobe 与现有千问视觉分类服务。
- 本地 JSON Store 保存任务记录，素材盘 manifest 作为可恢复事实源。

## Commands

- 语法检查：`npm run check`
- 全量测试：`npm test`
- Windows 打包：`npm run dist:win`
- 开发启动：`npm start`

## Project Structure

- `electron/main.cjs`：无边框窗口、安全 IPC、任务生命周期持久化。
- `electron/preload.cjs`：暴露窗口控制、款号列表、任务板读取接口。
- `electron/services/workspace-service.cjs`：读取款号素材盘并继续执行批次归档。
- `electron/services/task-board-service.cjs`：任务记录规范化、今日聚合与 manifest 去重补录。
- `prototype/v1/`：自定义标题栏、上传步骤、款号弹窗和任务板界面。
- `tests/`：服务和 UI 合同测试。

## Code Style

```js
function buildTodayTaskBoard({ records = [], batches = [], now = new Date() }) {
  const today = localDateKey(now);
  const tasks = mergeTaskSources(records, batches).filter((task) => localDateKey(task.createdAt) === today);
  return { date: today, tasks, materialCount: sum(tasks, "materialCount") };
}
```

- 文件路径全部在主进程校验和处理；渲染层不直接访问 Node.js。
- 状态使用明确枚举：`processing`、`completed`、`failed`、`interrupted`。
- 动态界面文本必须转义；交互使用原生按钮、表单和 dialog。

## Testing Strategy

- 单元测试验证本地日期、任务与 manifest 去重、今日计数、款号目录发现。
- UI 合同测试验证 `frame: false`、安全窗口 IPC、款号弹窗和任务页面均已接入。
- 保留并运行全部既有视频处理、AI 剪辑师和混剪测试。
- 在桌面应用验证拖动窗口、双击标题栏最大化、三颗窗口按钮、款号选择和任务板刷新。

## Boundaries

- Always：款号必须经过文件名清理；只写入当前素材盘根目录；任务失败也要落记录；升级保留旧用户状态。
- Ask first：改变素材盘根目录；移动或重分已有素材；改变分类模型或收费接口。
- Never：渲染层直接执行文件命令；覆盖同名批次；把上传原文件从用户原位置删除；上传 GitHub。

## Success Criteria

1. Windows 原生边框消失，自定义标题栏可拖动、最小化、最大化/还原和关闭。
2. 上传区不再要求提前填写款号；有文件后点击分析必定弹出款号选择窗口。
3. 弹窗列出已有款号、素材数量和最近处理时间，并支持新建款号。
4. 后台输出路径为 `<素材盘>/<款号>/<日期_批次>/<内容分类>`，manifest 中保留款号和任务 ID。
5. 任务板展示今日批次数、原视频数、分类素材数、待复核数、失败数和逐批次状态。
6. 旧状态可继续读取；全量测试通过；0.1.9 原位更新后仍从原快捷方式启动。

## Open Questions

- 无阻塞问题；批次名默认使用本地日期时间，用户可在款号弹窗中修改。
