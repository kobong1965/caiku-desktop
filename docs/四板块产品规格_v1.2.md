# 裁库四板块产品规格 v1.2

## Objective

面向抖音服饰带货视频生产，把“成品素材拆解为可复用镜头”与“从素材盘批量混剪新成片”做成一条可追溯、可复用、可删除的桌面工作流。

软件只保留四个一级业务板块，并按数据流排序：

1. 素材分类：上传某款号的一批成品素材，AI 分析、镜头拆分、字幕处理、分类复核后写入素材盘。
2. 素材管理：扫描素材盘，以款号为一级分类、素材内容为二级分类，支持勾选片段加入混剪选材篮。
3. 脚本管理：管理镜头结构、每段时长、字幕/口播文字与声音模式；可从竞品视频分析并生成可编辑模板。
4. 素材混剪：从素材库或款号快速选材，依次选择脚本、音乐/声音模式和生成数量，完成后显示并打开输出文件夹。

成功结果不是“生成一个文件”，而是每个新成片都能追溯使用的款号、素材片段、脚本版本、声音、音乐、模型检查结果和输出路径。

## Confirmed assumptions

- 用户上传的“成品素材”是待拆分源视频；原文件保留，拆分片段才进入可复用素材库。
- 款号是素材盘一级目录和主要筛选条件，内容类型是二级目录/标签。
- 脚本允许全程口播、部分口播、纯音乐三种模式；没有口播的段落仍可配置屏幕字幕。
- 竞品分析产出可编辑的结构化脚本模板，不覆盖原竞品文件，也不直接复制发布。
- 最短素材片段固定为 2 秒；统一输出 1080×1920、9:16、H.264/AAC。

## Core workflow

### 1. 素材分类

1. 新建批次：填写款号（例如 918）、批次名和备注。
2. 添加多个源视频：每个文件显示名称、时长、分辨率、重复状态和删除按钮。
3. 开始前检查：千问密钥、素材盘空间、文件可读性、重复文件、最短时长和款号目录。
4. 自动处理：镜头检测 → 合并不足 2 秒片段 → 抽帧 → Qwen 视觉分类 → 原字幕处理 → 1080p 竖屏标准化。
5. 分类复核：逐片段预览、修改二级分类、查看置信度/理由、删除片段或重新分析。
6. 提交素材盘：保存到 `素材盘/款号/内容分类/批次`，并更新 manifest 和素材索引。
7. 完成反馈：显示新增片段数、待复核数、失败数、保存目录，并提供“打开文件夹”和“去素材管理”。

### 2. 素材管理

1. 启动或刷新时扫描素材盘 manifest，建立索引，不复制文件。
2. 一级导航显示所有款号；选择款号后显示批次和二级内容分类数量。
3. 二级分类固定为人物穿搭、整体展示、细节讲解、测评对比、动作展示、口播、其他、不可用。
4. 支持搜索名称、款号、批次、标签；支持时长、使用次数、复核状态筛选。
5. 勾选片段后进入持久化“本次混剪选材篮”，切换页面不会丢失。
6. 选材篮显示款号、分类覆盖、总时长、数量和缺口；可删除单项、清空或进入素材混剪。
7. 单个素材删除分两种：从选材篮移除；从素材盘删除。后者显示引用影响并移入系统回收站。

### 3. 脚本管理

1. 脚本列表支持新建、复制、重命名、版本说明、搜索和删除。
2. 新建来源：空白脚本、已有脚本复制、竞品视频分析。
3. 每个脚本包含总时长、声音模式、目标款号/品类和多个时间段。
4. 每个时间段包含起止时间、目标素材分类、画面要求、屏幕字幕、口播文字、是否需要口播、转场/节奏备注。
5. 纯音乐模式允许全部口播文字为空；部分口播模式允许逐段关闭口播。
6. 竞品分析流程：添加竞品视频 → 镜头拆分 → 画面结构识别 → 字幕/文字信息提取 → 节奏与转场总结 → 生成可编辑草稿 → 保存为模板。
7. 竞品分析记录、竞品源视频引用、脚本和脚本段落都具备删除按钮。
8. 保存前校验总时长与分段时长、空白字幕是否合理、分类覆盖和风险词；警告不等于自动发布许可。

### 4. 素材混剪

1. 选材：继续使用素材管理的选材篮，或按款号一键加载后再增删片段。
2. 选脚本：显示脚本时长、声音模式、分类需求和当前素材覆盖率。
3. 选声音：根据脚本决定 AI/本地口播、部分口播或纯音乐；纯音乐不要求配音。
4. 选音乐：添加一个或多个音乐候选，每个都可删除；设置音量、循环和人声出现时自动压低。
5. 生成设置：填写混剪数量、随机种子、同片段重复上限和差异化策略。
6. 生成前检查：素材时长、脚本覆盖、声音资源、音乐、磁盘空间、风险词和输出规格。
7. 开始混剪：逐条生成，单条失败不阻断其他任务；任务卡可取消和删除。
8. AI 质检：千问核对关键帧与脚本/可见字幕，本地规则核对极限词/违禁词，音轨按脚本声音模式检查，技术规格逐条记录；逐字口播一致性留给后续语音转写能力，当前界面不得伪称已完成。
9. 完成弹窗：显示成功/失败数量与输出目录，主操作为“打开混剪文件夹”，次操作为“查看质检报告”。

## Universal delete contract

凡界面上存在“添加”能力的对象，必须存在对应删除入口：源视频、批次、拆分片段、外部素材、选材篮条目、脚本、脚本段落、竞品分析记录、音乐、配音、混剪任务和生成成片。

- 仅解除引用：立即执行，可撤销或重新添加。
- 删除本地文件：显示对象名称、路径、引用项目数量，二次确认后移入系统回收站。
- 批量删除：显示总数量和受影响款号/工程。
- 删除正在使用对象：先列出引用，再允许继续；相关项目进入“缺少资源”状态。
- 删除操作完成后必须更新 manifest、素材索引、选材篮和混剪项目，不留下失效引用。

## Data model

- `SourceBatch`: sku、batchName、sourceFiles、processingStatus、manifestPath、createdAt。
- `Material`: id、sku、batch、contentCategory、duration、filePath、confidence、reviewStatus、uses。
- `SelectionBasket`: id、name、skuScope、materialIds、coverage、updatedAt。
- `ScriptTemplate`: id、name、version、duration、voiceMode、sourceType、blocks、updatedAt。
- `ScriptBlock`: start、end、contentCategory、visualInstruction、subtitleText、voiceText、voiceEnabled、transitionNote。
- `CompetitorAnalysis`: id、sourcePath、status、shots、transcript、editingPattern、draftScriptId。
- `MixProject`: id、skuScope、materialIds、scriptId、voiceConfig、musicIds、outputCount、status、outputDir。
- `MixOutput`: id、projectId、filePath、qualityReportPath、status、sourceTrace。

## Tech stack and project structure

- Electron 43、原生 HTML/CSS/JavaScript、Node.js、FFmpeg/FFprobe、Qwen 视觉 API。
- `electron/`：桌面主进程、IPC、安全存储。
- `electron/services/`：视频、分类、素材盘索引、脚本/混剪服务。
- `prototype/v1/`：四板块 UI 与交互。
- `tests/`：Node 单元与集成测试。
- `docs/`：产品、架构、交互规格。
- `tasks/`：实施计划与验收任务。

## Code style

```js
function removeFromSelection(materialId) {
  appState.editingMaterialIds = appState.editingMaterialIds.filter((id) => id !== materialId);
  renderSelectionBasket();
  scheduleProjectSave();
}
```

- 状态变化集中在明确命名的函数中，渲染函数不删除磁盘文件。
- 所有磁盘删除都通过主进程 `trashPath`，渲染进程不直接访问文件系统。
- 每个无文字图标按钮必须有 `aria-label`；每个异步动作提供加载、成功和失败状态。

## Testing strategy

- 单元测试：分段下限、分类解析、删除引用清理、脚本时间校验、纯音乐模式校验。
- 集成测试：素材盘扫描 → 素材选择 → 脚本匹配 → 混剪输入参数。
- UI 验收：四个一级导航、空/加载/失败状态、所有添加对象删除入口、键盘操作。
- 安装验收：0.1.2 原位覆盖，保持安装路径、桌面快捷方式和用户数据。

## Boundaries

- Always：保留源视频；输出固定 1080p 9:16；低于 2 秒不进入正式素材；所有添加对象可删除；AI 结果可复核。
- Ask first：永久清空整个款号、覆盖现有批次、改变素材盘根目录、上传第三方平台。
- Never：明文保存 API Key；伪造 AI 分析；静默删除磁盘文件；把未通过检查描述为可直接投放。

## Success criteria

- 一级导航只有素材分类、素材管理、脚本管理、素材混剪四项，顺序一致。
- 918 款号的一批视频可从素材分类处理并写入 918 一级目录及内容二级目录。
- 素材管理能显示素材盘款号和内容分类，并把勾选项带入混剪。
- 脚本支持无口播、部分口播和全口播，段落明确时间、字幕与画面要求。
- 竞品分析入口可形成可编辑、可保存、可删除的脚本草稿流程。
- 混剪只要求当前声音模式实际需要的资源；纯音乐模式不再强制配音。
- 混剪完成后弹窗显示输出目录并可打开文件夹。
- 所有可添加对象均可删除，磁盘删除使用二次确认和回收站。
