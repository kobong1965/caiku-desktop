# 裁库 v0.1.3 简化首页设计说明

## Single job

素材分类首页只帮助用户完成一件事：把一批带货视频添加进来并开始 AI 分类。

## Information hierarchy

1. 款号与批次名称。
2. 添加视频区域与已选文件。
3. 开始 AI 分析。
4. 当前批次结果与后续动作。

## Removed from the visible interface

- 模块 1/4、步骤 1–5和所有数字圆点。
- 批次概览/上传并分析/分类复核页内标签。
- 输入 → AI处理 → 输出说明条。
- 下一步提示横幅。
- 五段流程进度线、预计完成时间和独立处理规则卡。
- 首屏最近批次大列表。

## Visual system

- 背景：纸白 `#f7f8f6`。
- 主文字：墨黑 `#171a17`。
- 辅助文字：石灰 `#697069`。
- 重点状态：薄荷绿 `#baf2df`。
- 边框：雾灰 `#dde2dc`。
- 排版：保持现有中文系统字体；标题使用紧凑粗体，正文不小于 13px。
- 版式：单列任务面板为主，批次结果作为次级横向面板；不使用装饰性编号。

## Interaction rules

- “添加视频”是首页唯一黑色主按钮。
- 没有视频时，“开始 AI 分析”不可用并说明原因。
- 每个已添加视频都有独立删除按钮。
- 磁盘删除仍经过确认并进入回收站。
- AI 模型、2 秒下限和固定 1080×1920 以一行状态说明呈现。
