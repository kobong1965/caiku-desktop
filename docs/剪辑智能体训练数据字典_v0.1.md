# 剪辑智能体训练数据字典 v0.1

## 存储原则

- 训练库固定保存在 `<素材盘>/_裁库智能体/训练库`。
- `cases.jsonl` 是只追加的版本日志；人工修改、删除和恢复都会产生新版本，不覆盖历史。
- 原素材、参考成品、配音和音乐只记录绝对路径，不复制视频文件。
- 市场脚本案例的 `finalVideo.sourceType` 固定为 `user_uploaded_reference`，表示由用户主动投喂。
- 当前合同不保存千川表现字段。

## TrainingCase

| 字段 | 类型 | 说明 |
|---|---|---|
| `schemaVersion` | number | 数据合同版本，当前为 1 |
| `caseId` | string | 跨版本稳定的案例编号 |
| `version` | number | 从 1 递增，禁止覆盖旧版本 |
| `status` | `active` / `deleted` | 软删除状态 |
| `sku` | string | 款号，可为空但建议填写 |
| `category` | string | 商品类目 |
| `caseType` | enum | `paired_edit`、`reference_only` 或 `negative_example` |
| `sourceMaterials` | array | 原素材路径、素材 ID 和人工分类；只保存引用 |
| `finalVideo` | object | 用户主动投喂的参考成品路径与创意 ID |
| `script` | object | 脚本快照和口播模式 |
| `voice` | object | 配音预设及音频路径 |
| `music` | object | 音乐路径和节拍信息 |
| `goldTimeline` | array | 人工确认的时间线 |
| `labels` | object | 1–5 分、接受状态和原因 |
| `rights` | object | 用户拥有或获授权的确认状态 |
| `analysisVersion` | string | 分析规则版本 |
| `contentHash` | string | 当前内容的 SHA-256 哈希 |
| `createdAt` / `updatedAt` | ISO string | 创建和本版本更新时间 |

## 删除与恢复

- 删除案例时追加 `status: deleted` 版本，并在 `trash/cases.jsonl` 留下记录。
- 默认查询不返回删除案例；带 `includeDeleted` 才能查看。
- 恢复案例追加新的 `active` 版本，不删除历史墓碑。
- 软件的删除按钮只改变训练库案例状态，不操作用户投喂的原视频文件。
