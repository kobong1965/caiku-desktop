# V1 最终 UI 与点击交互说明

## 1. 最终设计目标

这个软件的核心不是查看统计数据，而是把一批原视频稳定地处理成可混剪素材。因此最终界面围绕一条不可打乱的生产流程设计：

```text
导入原片 → 切分分类 → 清除字幕 → 自动混剪 → 导出成片
```

工作台只回答三个问题：当前是哪一批、处理到了哪里、下一步该做什么。

## 2. 已删除的无关窗口元素

- 删除全局搜索框：v1 素材按款号和批次组织，首屏无需全局搜索。
- 删除用户头像与通知中心：v1 是单机单用户版本，没有协作通知需求。
- 删除装饰性分类圆环和大数字仪表卡：保留与当前决策直接相关的合格片段、待处理数量和预计完成时间。
- 删除“应用列表、工作时长”等参考图内容：与视频素材处理无关。
- 删除单独占据大面积的混剪推荐卡：只有素材处理完成后才在混剪步骤出现。
- 删除重复的导航和快捷入口：每项主要任务只保留一个明确入口。

## 3. 最终信息结构

- 左侧：五步素材生产线和设置。
- 顶部：当前页面、当前款号/批次、素材盘状态、导入视频。
- 中部：当前步骤的主要工作区。
- 右侧：只显示当前步骤需要的规则、参数或检查结果。
- 底部反馈：短时 Toast；需要确认的操作使用对话框；长任务使用进度对话框。

## 4. 全局点击交互

| 点击位置 | 结果 |
|---|---|
| 左侧五个流程步骤 | 切换到对应页面，更新页面标题和当前导航状态 |
| 左侧设置 | 打开本地软件设置 |
| 当前款号/批次 | 展开批次列表 |
| 批次列表项 | 切换当前批次并显示反馈 |
| 素材盘状态 | 显示素材盘路径和剩余容量 |
| 导入视频 | 进入导入原片页面 |
| 弹窗空白遮罩或关闭按钮 | 关闭可取消弹窗 |
| Esc | 关闭批次菜单或当前可取消弹窗 |

## 5. 工作台交互

| 点击位置 | 结果 |
|---|---|
| 查看片段 | 进入分类校对，并自动筛选待处理片段 |
| 自动合并并继续 | 合并两个短片段，将待处理数量更新为 0，并显示通过状态 |
| 视频 1 / 视频 2 | 切换当前原视频 |
| 打开批次目录 | 提示调用 Windows 资源管理器定位目录 |
| 原字幕处理规则 | 进入清除字幕步骤 |
| 保存到款号目录 | 进入路径设置 |
| 进入分类校对 | 打开片段编辑器 |
| 最近批次行 | 切换并打开所选批次 |

## 6. 导入原片交互

| 点击位置 | 结果 |
|---|---|
| 款号、批次名称 | 实时更新目标保存目录 |
| 添加原视频 | 打开系统文件选择器 |
| 拖入视频 | 校验格式后加入文件列表 |
| 文件行 × | 从当前批次移除，不删除原文件 |
| 复制原视频开关 | 控制是否在批次目录保留原片副本 |
| 开始分析 | 校验款号、批次、视频文件；显示进度；完成后返回工作台 |
| 取消 | 不建立批次，返回工作台 |

## 7. 切分与分类交互

| 点击位置 | 结果 |
|---|---|
| 分类筛选 | 只显示对应内容类型或待处理片段 |
| 选中待处理 | 自动进入待处理筛选并选中首个问题片段 |
| 素材卡 | 在右侧打开片段预览和编辑属性 |
| 播放按钮 | 打开大预览弹窗 |
| 内容分类 | 修改片段分类 |
| 片段名称 | 修改保存名称 |
| 从播放点拆分 | 预估拆分后时长；任一片段低于 2 秒时阻止操作 |
| 与下一段合并 | 合并时长、名称和片段状态，重新执行 2 秒检查 |
| 标为不可用 | 二次确认后移出正式素材列表，原视频仍保留 |
| 保存当前片段 | 写入当前片段属性并显示反馈 |
| 保存分类 | 保存整个批次分类清单 |
| 下一步 | 进入清除字幕 |

## 8. 清除字幕交互

| 点击位置 | 结果 |
|---|---|
| 按住查看原画 | 按住期间显示原字幕，松开恢复修复后画面 |
| 播放 | 播放/暂停当前片段预览 |
| 上一个 / 下一个 | 在需要检查的片段间切换 |
| 画面修复 / 安全裁切 / 区域模糊 | 切换字幕处理策略和说明 |
| 修复范围滑块 | 实时调整检测遮罩扩展范围 |
| 显示检测遮罩 | 在预览上显示或隐藏修复区域 |
| 应用到同位置片段 | 批量套用当前策略 |
| 确认并继续 | 保存字幕检查结果并进入混剪 |

## 9. 自动混剪交互

| 点击位置 | 结果 |
|---|---|
| 脚本卡 | 选择脚本并更新生成前检查 |
| 查看脚本 | 打开完整镜头顺序弹窗 |
| 配音行 | 试听并选择配音 |
| 音乐行 | 试听并选择背景音乐 |
| 开始混剪 | 显示生成进度；完成后进入导出中心 |
| 返回检查素材 | 返回分类校对 |

## 10. 导出与设置交互

| 点击位置 | 结果 |
|---|---|
| 打开文件位置 | 调用 Windows 资源管理器定位成片 |
| 播放成片 | 打开成片预览弹窗 |
| 重新混剪 | 返回混剪设置并保留当前选择 |
| 暂停 / 继续 | 切换导出任务运行状态 |
| 取消任务 | 二次确认后取消，临时文件进入缓存回收区 |
| 重新选择并重试 | 更新失败任务并重新加入导出队列 |
| 设置分类 | 切换素材、规则、性能和导出设置 |
| 选择目录 | 调用 Windows 目录选择器 |
| 保存设置 | 保存并返回工作台 |

## 11. 状态与安全规则

- 低于 2 秒的拆分无法提交，错误信息会给出预计时长。
- 自动合并后，待处理数字、流程状态和片段状态同步更新。
- 删除、取消任务、标记不可用都需要二次确认。
- 原视频永远不由界面直接删除。
- 所有可点击元素使用原生按钮、输入框或选择器，支持键盘 Tab、Enter、Space 和 Esc。
- 320、768、1024、1440 像素宽度均不产生横向溢出。
