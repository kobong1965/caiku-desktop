# 裁库剪辑智能体训练系统验收报告 v0.1

验收日期：2026-08-23  
交付版本：裁库 v0.1.24  
验收结论：通过

## 1. 第一性原则

- 素材分类板块和人工复核结果是唯一素材事实源。
- 剪辑智能体读取款号、内容分类和用户本次勾选结果，不重新检测、过滤、删除、降级或修改人工确认分类。
- 市场脚本学习只分析用户主动上传的参考视频，不联网搜索、抓取或下载市场视频。
- 当前版本用“接受、拒绝、换镜、改切点、改文案、设为金标”形成训练反馈，不接入千川投放数据和评分。
- 口播、字幕、镜头使用同一份逐句文本与时间线；纯音乐脚本允许无口播。

## 2. 已交付能力

### 2.1 人工确认素材目录

- 按款号读取完整分类目录，保留每一个人工确认素材。
- 用户从素材管理勾选本次使用范围；未勾选素材不会进入本次计划。
- AI 计划展示目录总数、分类数量、实际选中素材及来源理由，便于人工审计。

### 2.2 用户投喂的市场脚本学习

- 支持 MP4、MOV、MKV、M4V、WebM 多文件拖拽或选择上传。
- 学习钩子、镜头角色、切点、口播、字幕、节奏与转场，保存为可复用剪辑配方。
- 每个训练任务可暂停、继续、重试、编辑、设为金标、软删除和恢复。
- 训练案例只保存本地文件路径及派生结构，不复制原视频，不从网络自动补充案例。

### 2.3 逐句智能编排

- 支持问题钩子、细节证据、上身结果、使用场景、克制引导等服装种草叙事角色。
- 逐句绑定目标内容分类、具体素材、口播、字幕和时间段。
- 连贯性门禁会拦截先下结论后给证据、画文不对应、主题跳转和重复结论。
- 接受或拒绝计划，以及人工换镜、改切点、改文案，均按版本追加保存，保留历史。

### 2.4 生成约束

- 分类素材原声关闭，混剪只使用选择的配音与音乐。
- 镜头片段下限 2 秒。
- 导出固定为 1080×1920、9:16、30fps、H.264；禁止裁切放大造成模糊。
- 字幕清理沿用已验收的全画幅高保真方案。
