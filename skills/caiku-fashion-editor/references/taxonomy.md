# 服装素材分类与证据强度

## 分类

- `outfit`：人物完整穿搭、上身效果、搭配关系。
- `overall`：商品全貌、正侧背面、全身远景。
- `detail`：面料、腰头、口袋、走线、褶皱等局部。
- `review`：前后、不同款式、优缺点或结论性测评。
- `action`：走动、转身、下蹲、拉伸、甩动等动态。
- `speech`：人物对镜口播，缺少更明确的商品动作或局部信息。
- `other`：证据不足或无法稳定归类。

## 证据状态

- `direct`：画面直接出现脚本所需动作、部位或可见商品事实。
- `indirect`：画面能承接沟通目标，但不能直接证明原卖点；文案必须收窄。
- `missing`：候选素材不能证明脚本卖点，必须列出缺口并改写。

模型置信度不是证据。只有素材画面能力卡记录的可见内容才是证据。
